* STATUS domain - domain Y0033FI_ICM_STATUS_N (SE11), NUMC(3). Gaps
* between values (multiples of 10) leave room to insert a new status
* later without renumbering; 900+ is reserved for statuses that are
* never persisted, and 990 for ERROR (can occur at any point in the
* flow, not a step in it).
* 000 is deliberately UNUSED here - it's the technical initial value
* of a NUMC(3) field, so a real status coded as 000 is indistinguishable
* from "never set" (SE16N hides it, IS INITIAL wrongly matches it).
* 000 is reserved to mean "not set".

*&---------------------------------------------------------------------*
*& Class LCL_ALV_EVENTS - hotspot click handler (shared)
*&---------------------------------------------------------------------*
*& Handles clicks on the EDOC_GUID and BELNR_FI columns of the main
*& item grid (screens 100/200 - see BUILD_FIELDCAT in Y0033FI_ICMS_F01
*& for the HOTSPOT = 'X' marking). Registered once per grid via
*& SET HANDLER in each screen's PBO module.
*&---------------------------------------------------------------------*
CLASS lcl_alv_events DEFINITION.
  PUBLIC SECTION.
    CLASS-METHODS on_hotspot_click
      FOR EVENT hotspot_click OF cl_gui_alv_grid
      IMPORTING e_row_id e_column_id.
ENDCLASS.

CLASS lcl_alv_events IMPLEMENTATION.

  METHOD on_hotspot_click.

    READ TABLE git_item INTO gwa_item INDEX e_row_id-index.
    CHECK sy-subrc = 0.

    CASE e_column_id-fieldname.

      WHEN 'DOCNUM'.
        CHECK gwa_item-docnum IS NOT INITIAL.
        " J1BNFE is a Report Transaction (screen 1000 of
        " J_1BNFE_MONITOR) - confirmed the BUK/JEF SET PARAMETER ID
        " approach doesn't reliably work because Document Number is a
        " SELECT-OPTIONS (range) field on that report, and
        " SET PARAMETER ID only works for single-value PARAMETER
        " fields. Using SUBMIT directly instead - same pattern as
        " EDOC_COCKPIT. Selection text for the field is confirmed as
        " DOCNUM.
        DATA: BEGIN OF ls_so_docnum,
                sign   TYPE c LENGTH 1 VALUE 'I',
                option TYPE c LENGTH 2 VALUE 'EQ',
                low    TYPE j_1bdocnum,
                high   TYPE j_1bdocnum,
              END OF ls_so_docnum.
        DATA lt_so_docnum LIKE TABLE OF ls_so_docnum.

        CLEAR ls_so_docnum-high.
        ls_so_docnum-low = gwa_item-docnum.
        APPEND ls_so_docnum TO lt_so_docnum.

        " CREDAT (Created On, from J_1BNFE_ACTIV-CREDAT, data element
        " J_1BCREDAT - confirmed via F1 -> Technical Information)
        " defaults to today when left blank, which excludes older
        " documents - pass a wide range instead so it never restricts anything. BUKRS is filled directly (best
        " guess: a single PARAMETER, the common case for a company
        " code field) - if either field turns out to be the other
        " type (PARAMETER vs SELECT-OPTIONS), this SUBMIT fails to
        " activate with a clear syntax error naming the field, easy
        " to fix from there.
        DATA: BEGIN OF ls_so_credat,
                sign   TYPE c LENGTH 1 VALUE 'I',
                option TYPE c LENGTH 2 VALUE 'BT',
                low    TYPE dats VALUE '19000101',
                high   TYPE dats VALUE '99991231',
              END OF ls_so_credat.
        DATA lt_so_credat LIKE TABLE OF ls_so_credat.
        APPEND ls_so_credat TO lt_so_credat.

        SUBMIT j_1bnfe_monitor
          WITH docnum IN lt_so_docnum
          WITH bukrs = gwa_item-bukrs
          WITH  date0 IN lt_so_credat
          AND RETURN.


      WHEN 'BELNR_FI'.
        CHECK gwa_item-belnr_fi IS NOT INITIAL.
        SET PARAMETER ID 'BUK' FIELD gwa_item-bukrs.
        SET PARAMETER ID 'BLN' FIELD gwa_item-belnr_fi.
        SET PARAMETER ID 'GJR' FIELD gwa_item-gjahr_fi.
        CALL TRANSACTION 'FB03' AND SKIP FIRST SCREEN.

      WHEN 'EDOC_GUID'.
        CHECK gwa_item-edoc_guid IS NOT INITIAL.
        " Confirmed pattern, reused from an existing program in this
        " landscape: EDOC_COCKPIT is a report (SUBMIT), not a
        " transaction, filtered via its SO_GUID selection option.
        DATA: BEGIN OF ls_so_guid,
                sign   TYPE c LENGTH 1 VALUE 'I',
                option TYPE c LENGTH 2 VALUE 'EQ',
                low    TYPE char32,
                high   TYPE char32,
              END OF ls_so_guid.
        DATA lt_so_guid LIKE TABLE OF ls_so_guid.

        CLEAR ls_so_guid-high.
        ls_so_guid-low = gwa_item-edoc_guid.
        APPEND ls_so_guid TO lt_so_guid.

        SUBMIT edoc_cockpit
          WITH so_guid IN lt_so_guid
          AND RETURN.

    ENDCASE.

  ENDMETHOD.

ENDCLASS.
