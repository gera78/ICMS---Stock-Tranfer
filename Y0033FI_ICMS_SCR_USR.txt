*&
*& Also included by Y0033FI_ICM_STOCK_TRANSFER_ADM (see
*& Y0033FI_ICMS_SCR_ADM) - everything here is common to both programs
*& (P_MNEW/P_MVIEW modes and their filters, identical field-for-field
*& in both). Y0033FI_ICMS_SCR_ADM adds only what is exclusive to the
*& admin program (P_MADM/P_MPARM/P_MLANE and the MAG1/MAG2 admin
*& filter shortcuts) in its own blocks, since a SELECTION-SCREEN block
*& opened here cannot be reopened there.
*&
*& INITIALIZATION/AT SELECTION-SCREEN OUTPUT/AT SELECTION-SCREEN can
*& each only be coded ONCE per program (activation error otherwise:
*& "the event ... was already specified"), so Y0033FI_ICMS_SCR_ADM
*& cannot declare its own copies of these three - its extra logic runs
*& through the dynamic PERFORM ('ADM_SCR_...') IF FOUND hooks below
*& instead. That syntax compiles fine even in the plain user program,
*& where those FORMs don't exist - IF FOUND just makes it a no-op there.
*&---------------------------------------------------------------------*

* Applied once here too, not just on MOD_CHG below - the individual
* filter checkboxes all carry PARAMETERS-level DEFAULT 'X', so without
* this the very first screen display would show every one of them
* checked regardless of the actual default mode, until the user
* touched a radio button and triggered MOD_CHG for the first time.
  PERFORM set_status_filter_defaults.

* Admin-only hook - see the header comment above for why this can't
* just be the admin program's own INITIALIZATION block. No-op (silent
* skip) when this include is compiled standalone, since FORM
* ADM_SCR_INIT then doesn't exist anywhere in the program.
  PERFORM ('ADM_SCR_INIT') IF FOUND.

AT SELECTION-SCREEN OUTPUT.
  LOOP AT SCREEN.
    IF screen-group1 = 'FS' AND p_mnew <> 'X'.
      screen-active = 0.  " hide entirely - only applies when searching new candidates
      MODIFY SCREEN.
    ENDIF.
    IF screen-group1 = 'FV' AND p_mview <> 'X'.
      screen-active = 0.  " hide entirely - only applies to view mode (also re-shown for admin review - see ADM_SCR_OUTPUT below)
      MODIFY SCREEN.
    ENDIF.
    IF screen-group1 = 'MV' AND p_mview <> 'X'.
      screen-active = 0.  " hide the "View" master checkboxes outside view mode
      MODIFY SCREEN.
    ENDIF.
  ENDLOOP.

* Admin-only hook - same reasoning as ADM_SCR_INIT above.
  PERFORM ('ADM_SCR_OUTPUT') IF FOUND.

AT SELECTION-SCREEN.
* ONLI = the user pressed Execute (F8), not just clicked a radio
* button/checkbox - only THEN is P_BUKRS actually required (and its
* authorization worth checking).
  IF sy-ucomm = 'ONLI'.
    IF p_bukrs IS INITIAL.
      MESSAGE 'Enter a Company Code' TYPE 'E'.
    ENDIF.
    PERFORM check_bukrs_authority USING p_bukrs.
    IF p_mnew = 'X'.
      PERFORM check_search_filters.
    ENDIF.
  ENDIF.

* Mode just switched (MOD_CHG fires for any change within the P_MNEW/
* P_MVIEW radio group, not only when P_MNEW itself is clicked) - reset
* each mode's own status filter to its defined default, exactly as if
* the screen were opened fresh in that mode. This intentionally
* overwrites any manual per-checkbox tweak made before switching away.
  IF sy-ucomm = 'MOD_CHG'.
    PERFORM set_status_filter_defaults.
  ENDIF.

* "Master" checkboxes (B3B) - group-toggle the real filter checkboxes
* when clicked. See the block comment above P_MVG1 for what each
* group covers.
  CASE sy-ucomm.
    WHEN 'MVG1'.
      p_vca = p_mvg1.  p_vcd = p_mvg1.
    WHEN 'MVG3'.
      p_vpo = p_mvg3.
    WHEN 'MVG2'.
      p_vrj = p_mvg2.  p_vap = p_mvg2.  p_vpf = p_mvg2.  p_vcb = p_mvg2.  p_vpg = p_mvg2.
      p_vrr = p_mvg2.  p_vrv = p_mvg2.  p_ver = p_mvg2.
  ENDCASE.

* Keep the master checkboxes honest: recompute them from their actual
* children on EVERY round trip (not just when the master itself was
* clicked) - otherwise switching between Search/View (or any other
* trip to the server, e.g. pressing Execute) kept showing whichever
* value the master had last, even after a child was unchecked
* individually, instead of tracking its children's real combined state.
  p_mvg1 = COND #( WHEN p_vca = abap_true AND p_vcd = abap_true
                    THEN abap_true ELSE abap_false ).
  p_mvg3 = COND #( WHEN p_vpo = abap_true THEN abap_true ELSE abap_false ).
  p_mvg2 = COND #( WHEN p_vrj = abap_true AND p_vap = abap_true AND p_vpf = abap_true AND p_vcb = abap_true
                         AND p_vpg = abap_true AND p_vrr = abap_true AND p_vrv = abap_true
                         AND p_ver = abap_true
                    THEN abap_true ELSE abap_false ).

* Admin-only hook - same reasoning as ADM_SCR_INIT above. Handles
* MOD_CHG2, MAG1/MAG2 and the P_MADM-specific status filter reset -
* none of which this include knows anything about.
  PERFORM ('ADM_SCR_EVENT') IF FOUND.

*&---------------------------------------------------------------------*
*&      Form  SET_STATUS_FILTER_DEFAULTS
*&---------------------------------------------------------------------*
* Resets the per-status filter checkboxes (B3A/B3B) to the current
* mode's default set. Called both from INITIALIZATION (so the very
* first screen display already matches the default mode, instead of
* showing every checkbox checked - their PARAMETERS-level DEFAULT 'X'
* only makes sense as a safe fallback) and from AT SELECTION-SCREEN on
* MOD_CHG (every later mode switch).
*
* Only handles P_MNEW/P_MVIEW - the two modes this include itself
* knows about. Called unconditionally above regardless of which
* program is running; it is a no-op whenever P_MADM/P_MPARM/P_MLANE is
* selected, since neither branch matches. The admin program applies
* its own P_MADM-specific reset separately, via the ADM_SCR_INIT/
* ADM_SCR_EVENT hooks above calling SET_ADM_STATUS_DEFAULTS
* (Y0033FI_ICMS_SCR_ADM).
*---------------------------------------------------------------------*
FORM set_status_filter_defaults.
  IF p_mnew = 'X'.
    p_sre = abap_true.  p_snc = abap_false.  p_ser = abap_false.
  ELSEIF p_mview = 'X'.
    p_vca = abap_true.   p_vcd = abap_true.                    " needs my action (010, 050)
    p_vpo = abap_false.                                        " reversal (040) - off by default
    p_vrj = abap_false.  p_vap = abap_false.  p_vpf = abap_false.  p_vcb = abap_false.
    p_vpg = abap_false.  p_vrr = abap_false.  p_vrv = abap_false.  p_ver = abap_false. " others
  ENDIF.
ENDFORM.
