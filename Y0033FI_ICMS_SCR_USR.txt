SELECTION-SCREEN BEGIN OF BLOCK b1 WITH FRAME TITLE TEXT-b01.
PARAMETERS:
  p_bukrs TYPE bukrs OBLIGATORY.
* Ship-from/ship-to are no longer fixed screen parameters - eligibility
* and direction now come entirely from Y0033FI_ICM_LANE (see FORM
* MATCH_LANE / SELECT_CANDIDATE_DOCUMENTS in Y0033FI_ICMS_F01).
SELECT-OPTIONS:
  s_datum  FOR sy-datum,
  s_nfenum FOR j_1bnfdoc-nfenum,
* S_LCTO only applies in view mode - nothing is posted yet in search
* mode, so it is hidden there (same MODIF ID FV as the status filter).
  s_lcto   FOR sy-datum MODIF ID fv.
* TODO (Q5/Q8): reference date for selection still pending - uses
* nota fiscal issue date for now.
SELECTION-SCREEN END OF BLOCK b1.

SELECTION-SCREEN BEGIN OF BLOCK b2 WITH FRAME TITLE TEXT-b02.
* USER-COMMAND on P_MNEW forces an immediate screen refresh on click
* (without it, AT SELECTION-SCREEN OUTPUT only reruns on the next
* Enter/round trip, so the filter block below would not hide/show
* right away).
PARAMETERS:
  p_mnew  RADIOBUTTON GROUP mod DEFAULT 'X' USER-COMMAND mod_chg,   " search new candidates
  p_mview RADIOBUTTON GROUP mod.               " view my candidates
SELECTION-SCREEN END OF BLOCK b2.

SELECTION-SCREEN BEGIN OF BLOCK b3a WITH FRAME TITLE TEXT-b3a.
* Status filter for "Search New Candidates" - every status a fresh
* search can produce, before anything is saved. All checked by
* default; selection text of each field is the label shown next to
* its checkbox. Applied in GET_STATUS_FILTER_SEARCH/APPLY_STATUS_FILTER
* (Y0033FI_ICMS_F01), right after the search pipeline builds GIT_ITEM.
PARAMETERS:
  p_sre TYPE char1 AS CHECKBOX DEFAULT 'X' MODIF ID fs,  " Ready to Save
  p_snc TYPE char1 AS CHECKBOX DEFAULT 'X' MODIF ID fs,  " Not a Candidate
  p_ser TYPE char1 AS CHECKBOX DEFAULT 'X' MODIF ID fs.  " Error
SELECTION-SCREEN END OF BLOCK b3a.

SELECTION-SCREEN BEGIN OF BLOCK b3b WITH FRAME TITLE TEXT-b3b.
* Status filter for "View My Candidates" - every status a saved item
* can be in. All checked by default.
PARAMETERS:
  p_vca TYPE char1 AS CHECKBOX DEFAULT 'X' MODIF ID fv,  " Candidate
  p_vap TYPE char1 AS CHECKBOX DEFAULT 'X' MODIF ID fv,  " Approved
  p_vpg TYPE char1 AS CHECKBOX DEFAULT 'X' MODIF ID fv,  " Posting
  p_vpo TYPE char1 AS CHECKBOX DEFAULT 'X' MODIF ID fv,  " Posted
  p_vcd TYPE char1 AS CHECKBOX DEFAULT 'X' MODIF ID fv,  " Cancel Detected
  p_vrr TYPE char1 AS CHECKBOX DEFAULT 'X' MODIF ID fv,  " Reversal Requested
  p_vrv TYPE char1 AS CHECKBOX DEFAULT 'X' MODIF ID fv,  " Reversed
  p_ver TYPE char1 AS CHECKBOX DEFAULT 'X' MODIF ID fv.  " Error
SELECTION-SCREEN END OF BLOCK b3b.

INITIALIZATION.
  gv_id_exec = sy-uname && sy-datum && sy-uzeit.

AT SELECTION-SCREEN OUTPUT.
  LOOP AT SCREEN.
    IF screen-group1 = 'FS' AND p_mnew <> 'X'.
      screen-active = 0.  " hide entirely - only applies when searching new candidates
      MODIFY SCREEN.
    ENDIF.
    IF screen-group1 = 'FV' AND p_mview <> 'X'.
      screen-active = 0.  " hide entirely - only applies to view mode
      MODIFY SCREEN.
    ENDIF.
  ENDLOOP.
