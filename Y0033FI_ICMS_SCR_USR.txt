* Not OBLIGATORY - that flag validates on every PAI round trip, which
* fires just from clicking a mode radio button (P_MNEW has
* USER-COMMAND) and gets in the way of navigating the screen before
* the user is done. Checked manually below instead, only when the
* user actually presses Execute (SY-UCOMM = 'ONLI').

  p_bukrs TYPE bukrs.
* Ship-from/ship-to are no longer fixed screen parameters - eligibility
* and direction now come entirely from Y0033FI_ICM_LANE (see FORM

  s_datum  FOR sy-datum,
  s_nfenum FOR j_1bnfdoc-nfenum,

* mode, so it is hidden there (same MODIF ID FV as the status filter).

* nota fiscal issue date for now.

AT SELECTION-SCREEN OUTPUT.
  LOOP AT SCREEN.
    IF screen-group1 = 'FS' AND p_mnew <> 'X'.
      screen-active = 0.  " hide entirely - only applies when searching new candidates
      MODIFY SCREEN.
    ENDIF.
    IF screen-group1 = 'FV' AND p_mview <> 'X'.
      screen-active = 0.  " hide entirely - only applies to view mode
      MODIFY SCREEN.
    ENDIF.
  ENDLOOP.

AT SELECTION-SCREEN.
* ONLI = the user pressed Execute (F8), not just clicked a radio
* button/checkbox - only THEN is P_BUKRS actually required.
  IF sy-ucomm = 'ONLI' AND p_bukrs IS INITIAL.
    MESSAGE 'Enter a Company Code' TYPE 'E'.
  ENDIF.
