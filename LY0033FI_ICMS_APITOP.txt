*&---------------------------------------------------------------------*
*& CR 16002 - API for a single nota fiscal (DOCNUM), used by class
*& Y0033CL_ICMS_STOCK_TRANSFER. Reuses the report programs' own
*& includes (TOP/F01/F02) so the logic is never duplicated - see the
*& INCLUDE statements added to the main program SAPLY0033FI_ICMS_API.
*&
*& The shared FORMs read a few selection-screen fields of the report
*& programs (S_*, P_*). A function group has no selection screen, so
*& they are declared here as plain ranges/flags with the SAME names and
*& types - API_PREPARE (Y0033FI_ICMS_F03) fills them for each call.
*&---------------------------------------------------------------------*
FUNCTION-POOL y0033fi_icms_api MESSAGE-ID y0033icms.

INCLUDE y0033fi_icms_top.

* (Y0033FI_ICMS_SCR_USR / Y0033FI_ICMS_SCR_ADM) - same names/types.

  s_nfenum TYPE ty_r_nfenum,

  s_series TYPE RANGE OF j_1bnfdoc-series,
  s_docdat TYPE RANGE OF j_1bnfdoc-docdat,
  s_autdat TYPE RANGE OF sy-datum,
  s_acckey TYPE RANGE OF y0033fi_icm_edoc-accesskey,
  s_lcto   TYPE RANGE OF sy-datum,
  s_actdat TYPE RANGE OF sy-datum,
  p_asav   TYPE char1,
  p_aapr   TYPE char1,
  p_arej   TYPE char1,
  p_apst   TYPE char1,
  p_mode1  TYPE char1,
  p_mode2  TYPE char1.
